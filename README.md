# AdventureWorks Sales Analysis

## Project Overview

This project involves analysing the AdventureWorks dataset to understand sales performance, profitability and customer trends.

I used Microsoft Excel, SQL, Power BI and Tableau to analyse the data and create dashboards. The analysis focuses on sales revenue, production costs, profit, product performance and regional sales.

## Technologies Used

- Microsoft Excel
- SQL
- Power BI
- Tableau

## Key Performance Indicators

The dashboards present the following business metrics:

| KPI | Value |
|---|---:|
| Total Sales | ₹29.36M |
| Total Cost | ₹17.28M |
| Total Profit | ₹12.08M |
| Total Customers | 18,484 |
| Profit Margin | 41.15% |

## Analysis Covered

The project includes the following analysis:

- Comparison of sales revenue and production costs.
- Monthly, quarterly and yearly sales trends.
- Identification of top-performing products.
- Analysis of top customers based on sales.
- Comparison of sales across different regions.
- Analysis of product category performance.

## Dashboards

### 1. Microsoft Excel
Created an interactive dashboard to analyse sales, production costs and product performance using charts, KPI cards and filters.

### 2. Power BI
Built a dashboard to track sales, profit and orders, with visualisations for regional sales, product categories and sales trends.

### 3. Tableau
Created visual reports to compare sales and production costs and explore customer, product and regional performance.
